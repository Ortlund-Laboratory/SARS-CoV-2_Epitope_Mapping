## Tracking Clusters Over Time

We received antibodies from companies over a 37 month period. To see whether particular cluster types emerged at certain time periods, we logged the percentage of the cluster total obtained for each of these 37 months. Input data is given in raw_data_cluster_app_over_time.csv. We then used cluster_over_time.R to generate the dendrogram, cluster_time_heatmap.png.
